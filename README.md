# True Man Show 앨범 사이트

## 음원과 가사 추가
1. `audio/`에 공개할 MP3 또는 WAV 음원을 넣습니다.
2. `lyrics/`에 UTF-8 가사 텍스트를 넣습니다.
3. `album.js`의 `tracks`에 순서대로 등록합니다. 파일 이름과 확장자를 정확히 맞추세요.

```js
{
  title: '곡 제목',
  artist: '아티스트',
  audio: 'audio/01.mp3',
  lyrics: 'lyrics/01.txt',
  highlight: '이곳에 핵심 가사 한 줄을 입력하세요'
},
```

`highlight`는 아티스트명 아래에 인용문으로 표시됩니다. 빈 문자열이거나 생략하면 여백 없이 숨겨집니다. 곡을 바꾸면 해당 곡의 문구로 바뀝니다.

가사 파일은 한 줄에 한 문장씩 작성합니다. `[00:12.50] 가사`처럼 시간을 붙이면 재생 중 강조되고 클릭해 해당 위치로 이동할 수 있습니다. 일반 텍스트 가사도 지원합니다.

앨범 소개는 `introduction`에 입력합니다. 여러 줄이면 백틱으로 감싸세요.

## 미리보기와 배포
로컬 전용 모드는 해제되어 로컬과 공개 사이트 모두 `album.js`를 사용합니다. 기존 `album.local.js`는 사용하지 않으며 Git에서도 제외됩니다. `audio/`와 `lyrics/`는 이제 배포 대상입니다.

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

미리보기: http://127.0.0.1:4173/

변경 파일을 커밋하고 main에 push하면 GitHub Pages가 자동 배포합니다. 저장소와 음원은 공개됩니다.
