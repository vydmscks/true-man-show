# True Man Show 앨범 사이트

## 음원과 가사 추가
1. `audio` 폴더에 음원 파일을 넣습니다. 예: `01.mp3`.
2. `lyrics` 폴더에 UTF-8 텍스트 가사를 넣습니다. 예: `01.txt` (가사가 없다면 생략 가능).
3. `album.js`의 `tracks`에 순서대로 곡을 추가합니다.

```js
tracks: [
  { title: '첫 번째 곡', artist: 'TTL', audio: 'audio/01.mp3', lyrics: 'lyrics/01.txt' },
  { title: '두 번째 곡', artist: 'TTL', audio: 'audio/02.mp3' },
],
```

가사 파일은 한 줄에 한 문장씩 작성합니다. `[분:초.소수]`를 앞에 붙이면 재생 중 강조되고 누르면 해당 위치로 이동합니다. 시간 없이 적어도 가사는 표시됩니다.

```text
[00:12.50] 첫 번째 가사
[00:18.20] 두 번째 가사
```

앨범 소개는 `album.js`의 `introduction: ''`에 입력합니다. 여러 줄을 넣을 때는 백틱을 사용하세요. 변경 후 다시 배포해야 실제 사이트에 반영됩니다. 브라우저 정책상 처음 재생하려면 재생 버튼을 눌러야 할 수 있습니다.
