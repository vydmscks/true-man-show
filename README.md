# True Man Show 앨범 사이트

## 음원과 가사 추가
1. `audio/`에 공개할 MP3 또는 WAV 음원을 넣습니다.
2. `lyrics/`에 UTF-8 가사 텍스트를 넣습니다.
3. `album.js`의 `tracks`에 순서대로 등록합니다. 파일 이름과 확장자를 정확히 맞추세요.

```js
{
  title: '곡 제목',
  artist: '아티스트',
  audio: 'audio/01.mp3',
  lyrics: 'lyrics/01.txt',
  highlight: '이곳에 핵심 가사 한 줄을 입력하세요'
},
```

`highlight`는 아티스트명 아래에 인용문으로 표시됩니다. 빈 문자열이거나 생략하면 여백 없이 숨겨집니다. 곡을 바꾸면 해당 곡의 문구로 바뀝니다.

가사 파일은 한 줄에 한 문장씩 작성합니다. `[00:12.50] 가사`처럼 시간을 붙이면 재생 중 강조되고 클릭해 해당 위치로 이동할 수 있습니다. 일반 텍스트 가사도 지원합니다.

앨범 소개는 `introduction`에 입력합니다. 여러 줄이면 백틱으로 감싸세요.

## 미리보기와 배포
로컬 전용 모드는 해제되어 로컬과 공개 사이트 모두 `album.js`를 사용합니다. 기존 `album.local.js`는 사용하지 않으며 Git에서도 제외됩니다. `audio/`와 `lyrics/`는 이제 배포 대상입니다.

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

미리보기: http://127.0.0.1:4173/

변경 파일을 커밋하고 main에 push하면 GitHub Pages가 자동 배포합니다. 저장소와 음원은 공개됩니다.

## 로컬 가사가 보이지 않을 때
`index.html`을 더블클릭한 `file://` 주소에서는 브라우저가 가사 파일 읽기를 차단합니다. `preview.cmd`를 더블클릭하면 로컬 서버와 브라우저가 열립니다. 콘솔 창을 닫으면 서버도 종료됩니다.

## 글자별 타이밍 편집
미리보기 실행 후 `http://127.0.0.1:4173/timing.html`을 여세요. 공개 사이트의 `/timing.html`에서도 사용할 수 있습니다.

1. 곡 선택 → 가사 확인 또는 입력 → **가사 적용**.
2. **P**로 재생/일시정지, **Space**로 다음 글자의 시간을 기록합니다. 입력란에 커서가 있을 때는 단축키가 작동하지 않습니다.
3. 틀린 글자를 클릭해 위치를 선택하고 시간을 수정하거나 **되돌리기**를 누르세요. 0.5배속/0.75배속으로 천천히 들으며 기록할 수 있습니다.
4. **가사 파일 저장** → 내려받은 파일로 해당 `lyrics/*.txt`를 교체 → 커밋·배포.

타이밍은 브라우저에 임시 저장됩니다. 기기/브라우저를 바꾸기 전 파일을 저장하세요. 음원과 가사는 편집 중 별도 서버로 업로드하지 않습니다.

```text
<00:12.50>우<00:12.80>리 <00:13.10>서<00:13.40>로
```

기존 일반 텍스트 및 `[00:12.50] 문장` 형식도 그대로 사용할 수 있습니다. 한글은 음절(눈에 보이는 한 글자) 단위로 기록됩니다.
